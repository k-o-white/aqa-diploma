# Курсовая работа по автоматизации тестирования покупки тура

Проект предназначен для тестирования веб-сервиса, который предлагает купить тур по определённой цене двумя способами: оплатой по дебетовой карте или по заявке на кредит по данным банковской карты. 
В рамках проекта автоматизированы UI-сценарии формы оплатой по дебетовой карте. Подробно с заданием курсовой работы можно ознакомиться [по ссылке](https://github.com/netology-code/aqa-qamid-diplom/blob/main/README.md).

## Начало работы

Для запуска проекта локально нужно выполнить следующие действия.

### Prerequisites

Необходимо установить:
- Git;
- JDK 11;
- Docker Desktop;
- браузер Google Chrome.

### Установка и запуск

1. Клонировать репозиторий:

   ```bash
   git clone https://github.com/k-o-white/aqa-diploma.git
   cd aqa-diploma
   ```

2. Запустить Docker Desktop:

   ```bash
   docker desktop start
   ```

3. Запустить базу данных:

   ```bash
   docker compose up -d
   ```

4. Запустить приложение в терминале:

   ```bash
   java -jar artifacts/aqa-shop.jar
   ```

5. Открыть сервис в Google Chrome по адресу [http://localhost:8080](http://localhost:8080).

6. Открыть второй терминал и запустить автотесты:

   ```bash
   ./gradlew clean test
   ```

7. Создать отчёт Allure и открыть в браузере

   ```bash
   ./gradlew allureServe
   ```

8. Закрыть отчёт в терминале, нажав `Ctrl + C`, а затем `Y`

9. Перейти в терминал, в котором запущено приложение, завершить его работу, нажав `Ctrl + C`

10. Остановить контейнер базы данных:

    ```bash
    docker compose down
    ```
