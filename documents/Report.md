# Отчёт по итогам тестирования

Проведено ручное тестирование обеих форм приобретения тура: «Купить» и «Купить в кредит». Для формы «Купить» дополнительно выполнено автоматизированное тестирование пользовательского интерфейса и проверка сохранения результатов операций в базе данных.

По результатам тестирования зарегистрировано 11 дефектов в [GitHub Issues](https://github.com/k-o-white/aqa-diploma/issues). Дефекты 1-10 подтверждены автоматизированным тестированием, дефект [#11](https://github.com/k-o-white/aqa-diploma/issues/11) был обнаружен в ходе ручного тестирования формы «Купить в кредит». 

## Результаты автоматизированного тестирования

Для формы «Купить» выполнено 27 тест-кейсов: 5 позитивных и 22 негативных.

## Общие рекомендации

1. Определить требования к валидации полей: допустимые символы, форматы и граничные значения для каждого поля формы.
2. Уточнить обработку результатов оплаты: исключить противоречивые и повторные уведомления, обеспечить корректное отображение статуса платежа.
